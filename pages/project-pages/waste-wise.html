Waste Wise

Role: Creator & Designer • Tools: HTML, CSS, p5.js • August – December 2024

An informative website and embedded interactive game created as part of the Girls Who Code Leadership Academy. The project raises awareness about overconsumption through engaging design and interactive storytelling.

Back to projects

Overview

Waste Wise is a give-back project developed during the Girls Who Code Leadership Academy. The project combines informative web design with interactive gaming to educate users about the impact of overconsumption and encourage sustainable behavior change. The website serves as an educational platform while the embedded p5.js game provides an engaging, gamified learning experience.

My Role & Contributions

As the project creator, I owned the complete vision and execution:

  • Concept Development: Identified overconsumption as a meaningful social issue and designed an interactive approach to education
  • Web Design & Development: Built the informative website using HTML and CSS with a focus on clear information hierarchy and engaging visual design
  • Game Development: Created an interactive p5.js game embedded within the website to gamify the learning experience
  • User Education: Structured content to progressively educate users about overconsumption causes, impacts, and solutions

Project Context

Girls Who Code Leadership Academy: A four-month intensive leadership development program sponsored by RTX, focused on building leadership skills and creating meaningful community impact projects. Waste Wise represents my leadership initiative and commitment to social responsibility.

Process

1

2

3

Technical Stack

Frontend: HTML5, CSS3 • Game: p5.js • Focus: Responsive Design, Accessibility, User Engagement

Design Philosophy

The design emphasizes clarity and impact. The website uses compelling visuals and accessible language to make the issue of overconsumption relatable. The embedded game translates abstract concepts into concrete, interactive experiences where users can see the real-time consequences of consumption choices.
